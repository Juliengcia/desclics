# Desclics

Le numérique, expliqué clairement. Site d'information en français pour apprendre à se servir d'un ordinateur, d'un smartphone et d'Internet : démarches, sécurité, communication, intelligence artificielle. Gratuit, sans compte, sans publicité, sans traceur.

- Comment le projet est organisé : [CLAUDE.md](CLAUDE.md)
- Modifier le site à la main : [GUIDE.md](GUIDE.md)
- Historique : [CHANGELOG.md](CHANGELOG.md) · À faire : [BACKLOG.md](BACKLOG.md) · Visuels : [CAPTURES.md](CAPTURES.md)

## Lancer le site sur son ordinateur

```bash
npm install
npm run dev
```

Puis ouvrir l'adresse affichée (http://localhost:4321/desclics/).
