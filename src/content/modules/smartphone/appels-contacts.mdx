## Comment décrocher et raccrocher ? \{#decrocher-raccrocher\}

<Etapes titre="Décrocher ou refuser un appel">
1. Quand le téléphone sonne, le nom ou le numéro de l'appelant s'affiche.
2. Pour **décrocher** : touchez le bouton **vert**, ou faites-le glisser s'il porte une flèche.
3. Pour **refuser** : touchez le bouton **rouge**, ou faites-le glisser. L'appelant tombe sur votre messagerie.
4. Pour couper seulement la sonnerie : appuyez une fois sur un bouton de volume.
</Etapes>

<Etapes titre="Raccrocher">
1. Écartez le téléphone de votre oreille : l'écran se rallume.
2. Touchez le gros **bouton rouge** en bas de l'écran.
3. Si vous êtes sorti de l'appel (autre appli ouverte), touchez la **bulle ou la barre verte** en haut de l'écran pour y revenir, puis le bouton rouge.
</Etapes>

<Attention>
L'écran s'éteint pendant un appel quand le téléphone est contre l'oreille : c'est normal, il évite les appuis avec la joue. Il se rallume dès que vous l'écartez.
</Attention>

## Comment mettre le haut-parleur ? \{#haut-parleur\}

Pendant l'appel, touchez **Haut-parleur** (une icône de haut-parleur). Retouchez-la pour revenir à l'écouteur. Réglez le volume avec les boutons sur la tranche du téléphone.

Les autres boutons pendant un appel : **Silence** coupe votre micro, **Clavier** sert à taper des chiffres (serveur vocal « tapez 1 »).

## Comment appeler et enregistrer un contact ? \{#contacts\}

<Etapes titre="Appeler un numéro">
1. Ouvrez l'appli **Téléphone** (combiné vert).
2. Touchez **Clavier**, tapez le numéro.
3. Touchez le bouton vert.
</Etapes>

<Etapes titre="Enregistrer un contact">
1. Dans l'appli Téléphone, ouvrez **Récents** (ou **Historique**).
2. Touchez le numéro à enregistrer, puis **Créer un contact** ou **Ajouter aux contacts**.
3. Tapez le prénom et le nom.
4. Touchez **Enregistrer** (Android) ou **OK** (iPhone).
</Etapes>

<Astuce>
Ajoutez la relation au nom (« Marie, fille », « Dr Martin, généraliste ») : vous la retrouverez vite en tapant le début.
</Astuce>

## Comment écouter sa messagerie vocale ? \{#messagerie\}

<Definition terme="messagerie vocale">
La messagerie vocale, ou répondeur, enregistre les messages quand vous ne décrochez pas.
</Definition>

<Etapes titre="Écouter ses messages">
1. Ouvrez l'appli Téléphone, puis le **Clavier**.
2. Maintenez la touche **1** : le téléphone appelle votre messagerie.
3. Si rien ne se passe, composez le numéro de votre opérateur.
4. Suivez les instructions vocales.
</Etapes>

## Comment bloquer un numéro qui dérange ? \{#bloquer\}

<Onglets appareils={['android', 'iphone']}>
<Onglet appareil="android">

<Etapes titre="Bloquer un numéro (Samsung)">
1. Ouvrez l'appli **Téléphone**, puis **Récents**.
2. Touchez le numéro, puis l'icône **ⓘ** (informations).
3. Touchez **Bloquer**, puis confirmez.
</Etapes>

</Onglet>
<Onglet appareil="iphone">

<Etapes titre="Bloquer un numéro (iPhone)">
1. Ouvrez l'appli **Téléphone**, puis **Récents**.
2. Touchez **ⓘ** à droite du numéro.
3. Faites défiler et touchez **Bloquer ce correspondant**.
</Etapes>

</Onglet>
</Onglets>

<Astuce>
Contre le démarchage commercial, inscrivez gratuitement votre numéro sur **Bloctel**, la liste d'opposition officielle : <a href="https://www.bloctel.gouv.fr/" rel="noopener">bloctel.gouv.fr</a>.
</Astuce>

<Attention>
Un appel se présentant comme votre banque, la police ou un service public qui vous demande un code, de valider une opération ou d'installer une appli est une arnaque. Raccrochez et rappelez le numéro officiel vous-même.
</Attention>
