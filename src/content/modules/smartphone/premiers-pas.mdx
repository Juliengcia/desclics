## Comment allumer et déverrouiller le téléphone ? \{#allumer\}

<Definition terme="smartphone">
Un <Terme id="smartphone">smartphone</Terme> est un téléphone à écran tactile : on le commande avec les doigts. Il fonctionne avec <Terme id="android">Android</Terme> (Samsung et la plupart des marques) ou <Terme id="ios">iOS</Terme> (iPhone).
</Definition>

<Etapes titre="Allumer et déverrouiller">
1. Maintenez le **bouton latéral** (sur la tranche droite) enfoncé quelques secondes, jusqu'à voir le logo.
2. Pour réveiller l'écran ensuite, appuyez brièvement sur ce même bouton.
3. Glissez le doigt du bas vers le haut de l'écran.
4. Tapez votre **code**, ou présentez votre visage ou votre doigt si vous avez activé la reconnaissance.
</Etapes>

<Attention>
Choisissez un code que vous retenez, mais pas votre date de naissance. Notez-le dans un endroit sûr à la maison, jamais avec le téléphone.
</Attention>

## Comment se repérer sur l'écran ? \{#ecrans\}

- **L'écran d'accueil** : celui qui s'affiche après le déverrouillage, avec vos <Terme id="icone">icônes</Terme> principales.
- **La liste de toutes les applis** : sur Android, glissez du bas vers le haut de l'écran d'accueil. Sur iPhone, glissez vers la gauche jusqu'à la **Bibliothèque d'apps**.
- **Les réglages rapides** : Wi-Fi, son, lampe torche, luminosité.

<Onglets appareils={['android', 'iphone']}>
<Onglet appareil="android">

<Etapes titre="Ouvrir les réglages rapides (Android)">
1. Glissez un doigt du **haut** de l'écran vers le bas : les notifications apparaissent.
2. Glissez une seconde fois vers le bas : tous les réglages rapides s'affichent.
3. Touchez une icône pour l'activer ou la désactiver (elle change de couleur).
</Etapes>

</Onglet>
<Onglet appareil="iphone">

<Etapes titre="Ouvrir le centre de contrôle (iPhone)">
1. Glissez un doigt depuis le **coin en haut à droite** de l'écran vers le bas.
2. Touchez une icône pour l'activer ou la désactiver (elle s'allume en couleur).
3. Pour fermer, glissez vers le haut ou touchez un espace vide.
</Etapes>

</Onglet>
</Onglets>

## Comment revenir en arrière ou à l'accueil ? \{#navigation\}

<Onglets appareils={['android', 'iphone']}>
<Onglet appareil="android">

Selon le réglage du téléphone, vous avez soit **trois boutons** en bas de l'écran, soit une **barre** fine.

- Avec trois boutons : **‹** revient en arrière, **○** retourne à l'accueil, **|||** montre les applis ouvertes.
- Avec la barre : glissez du bas vers le haut pour l'accueil, glissez depuis le bord gauche ou droit vers le centre pour revenir en arrière.

</Onglet>
<Onglet appareil="iphone">

- Pour revenir à l'accueil : glissez du bas de l'écran vers le haut. Sur un iPhone avec bouton rond sous l'écran, appuyez dessus.
- Pour revenir en arrière dans une appli : touchez **‹** en haut à gauche, ou glissez depuis le bord gauche vers la droite.
- Pour voir les applis ouvertes : glissez du bas vers le haut et arrêtez-vous au milieu.

</Onglet>
</Onglets>

## Comment agrandir le texte ? \{#agrandir-texte\}

<Onglets appareils={['android', 'iphone']}>
<Onglet appareil="android">

<Etapes titre="Agrandir le texte sur Android (Samsung)">
1. Ouvrez **Paramètres** (la roue crantée).
2. Touchez **Affichage**.
3. Touchez **Taille et style de police** (ou **Taille de la police**).
4. Faites glisser le curseur vers la droite jusqu'à une taille confortable.
</Etapes>

</Onglet>
<Onglet appareil="iphone">

<Etapes titre="Agrandir le texte sur iPhone">
1. Ouvrez **Réglages**.
2. Touchez **Luminosité et affichage**.
3. Touchez **Taille du texte**.
4. Faites glisser le curseur vers la droite.
</Etapes>

</Onglet>
</Onglets>

<ARetenir>
Le texte agrandi s'applique à presque toutes les applis : messages, réglages, navigateur. Vous pouvez revenir en arrière à tout moment.
</ARetenir>

## Comment éteindre ou redémarrer ? \{#eteindre\}

<Onglets appareils={['android', 'iphone']}>
<Onglet appareil="android">

1. Ouvrez les réglages rapides (glisser deux fois du haut vers le bas).
2. Touchez l'icône **Marche/Arrêt**, en haut.
3. Choisissez **Éteindre** ou **Redémarrer**.

</Onglet>
<Onglet appareil="iphone">

1. Maintenez ensemble le **bouton latéral** et l'un des **boutons de volume**.
2. Faites glisser le curseur **Éteindre** vers la droite.
3. Pour rallumer, maintenez le bouton latéral jusqu'au logo Apple.

</Onglet>
</Onglets>

<Astuce>
Un téléphone qui rame se remet souvent d'aplomb après un simple redémarrage. Faites-le une fois par semaine.
</Astuce>
