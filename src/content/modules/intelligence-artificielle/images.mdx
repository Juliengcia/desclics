## Quels outils créent des images ? \{#outils\}

Plusieurs assistants savent créer des images à partir d'une description : **Copilot** (Microsoft), **ChatGPT**, **Le Chat** (Mistral), **Gemini**, ou des outils de mise en page comme **Canva**. Les versions gratuites limitent souvent le nombre d'images par jour.

## Comment décrire l'image voulue ? \{#decrire\}

<Etapes titre="Les éléments d'une bonne description">
1. **Le sujet** : « un panier de pommes rouges sur une table en bois ».
2. **Le style** : photo réaliste, aquarelle, dessin simple, affiche rétro.
3. **Les couleurs et l'ambiance** : couleurs chaudes, lumière d'automne.
4. **Le cadrage** : vue de près, format horizontal ou vertical (pour une affiche A4 : vertical).
</Etapes>

<Astuce>
Si le résultat ne convient pas, précisez : « sans personnes », « plus lumineux », « style plus simple ».
</Astuce>

## Comment créer une affiche ? \{#affiche\}

<Etapes>
1. Faites générer une **illustration** sans texte.
2. Téléchargez l'image (bouton de téléchargement ou appui long → Enregistrer).
3. Ouvrez un modèle d'affiche (Canva, traitement de texte, présentation) et insérez l'image.
4. Ajoutez **vous-même** le texte : titre, date, lieu. Les textes écrits par l'IA dans l'image sont souvent déformés ou mal orthographiés.
5. Exportez en PDF pour imprimer.
</Etapes>

## Quelles règles respecter ? \{#regles\}

<Attention>
- Ne créez pas d'image d'une **personne réelle** sans son accord, et jamais une image humiliante ou trompeuse : c'est interdit et peut être puni.
- Indiquez qu'une image est **générée par IA** quand vous la diffusez.
- Pour un usage commercial, lisez les conditions d'utilisation de l'outil.
</Attention>
