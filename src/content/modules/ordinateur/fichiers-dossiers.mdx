## Quelle différence entre un fichier et un dossier ? \{#fichier-dossier\}

<Definition terme="fichier et dossier">
Un <Terme id="fichier">fichier</Terme> est un document enregistré : une lettre, une photo, un PDF. Un <Terme id="dossier">dossier</Terme> est un rangement qui contient des fichiers, ou d'autres dossiers, comme une chemise cartonnée.
</Definition>

La fin du nom, après le point, s'appelle l'<Terme id="extension">extension</Terme> : elle indique le type de fichier. **.pdf** pour un PDF, **.jpg** pour une photo, **.docx** pour un document Word.

## Où voir mes fichiers ? \{#explorateur\}

<Onglets appareils={['windows', 'mac']}>
<Onglet appareil="windows">

<Etapes titre="Ouvrir l'Explorateur de fichiers">
1. Cliquez sur l'icône en forme de **dossier jaune** dans la barre des tâches, ou appuyez sur <Touches k="⊞+E" />.
2. À gauche, cliquez sur **Documents**, **Téléchargements** ou **Images**.
3. Double-cliquez sur un dossier pour l'ouvrir, puis sur un fichier pour l'afficher.
</Etapes>

</Onglet>
<Onglet appareil="mac">

<Etapes titre="Ouvrir le Finder">
1. Cliquez sur l'icône du **Finder** (un visage bleu et blanc), à gauche du Dock.
2. Dans la colonne de gauche, cliquez sur **Documents**, **Téléchargements** ou **Images**.
3. Double-cliquez sur un dossier pour l'ouvrir, puis sur un fichier pour l'afficher.
</Etapes>

</Onglet>
</Onglets>

Le <Terme id="explorateur-fichiers">Explorateur de fichiers</Terme> (Windows) et le <Terme id="finder">Finder</Terme> (Mac) font la même chose : ils montrent ce que contient l'ordinateur.

## Comment créer, renommer et déplacer ? \{#ranger\}

<Etapes titre="Créer un dossier">
1. Ouvrez le dossier dans lequel vous voulez le créer, par exemple Documents.
2. Faites un clic droit dans un espace vide, puis choisissez **Nouveau → Dossier** (Windows) ou **Nouveau dossier** (Mac).
3. Tapez son nom, puis appuyez sur <Touches k="Entrée" />.
</Etapes>

<Etapes titre="Renommer un fichier ou un dossier">
1. Faites un clic droit sur le fichier.
2. Choisissez **Renommer**.
3. Tapez le nouveau nom, sans toucher à l'extension (.pdf, .jpg…), puis <Touches k="Entrée" />.
</Etapes>

Pour **déplacer** un fichier, cliquez dessus, maintenez le bouton de la souris, faites-le glisser sur le dossier voulu, puis relâchez.

<Astuce>
Nommez vos fichiers avec trois éléments : quoi, qui, quand. Par exemple **facture-electricite-2026-10.pdf**. Vous le retrouverez sans l'ouvrir.
</Astuce>

## Où est le fichier que je viens de télécharger ? \{#telechargements\}

Quand vous <Terme id="telecharger">téléchargez</Terme> un fichier (une pièce jointe, une attestation), il arrive presque toujours dans le dossier **Téléchargements**.

<Etapes titre="Retrouver un fichier téléchargé">
1. Ouvrez l'Explorateur de fichiers ou le Finder.
2. Cliquez sur **Téléchargements** à gauche.
3. Le fichier le plus récent est en général en haut. Sinon, cliquez sur l'en-tête **Date de modification** pour trier.
4. Rangez-le aussitôt dans le bon dossier, avec un nom clair.
</Etapes>

<Astuce>
Dans le navigateur, <Touches k="Ctrl+J" /> affiche la liste des téléchargements récents.
</Astuce>

## Comment retrouver un fichier perdu ? \{#rechercher\}

<Etapes titre="Chercher un fichier par son nom">
1. Ouvrez l'Explorateur de fichiers ou le Finder.
2. Cliquez dans la case de recherche, en haut à droite.
3. Tapez un mot du nom du fichier, par exemple « facture ».
4. Attendez quelques secondes : les fichiers correspondants s'affichent.
</Etapes>

<Astuce>
Sur Mac, <Touches k="⌘+Espace" /> ouvre Spotlight : tapez un mot, il cherche dans tout le Mac.
</Astuce>

## Comment récupérer un fichier supprimé ? \{#corbeille\}

Un fichier supprimé va d'abord dans la <Terme id="corbeille">corbeille</Terme>. Tant qu'elle n'est pas vidée, il est récupérable.

<Etapes titre="Restaurer un fichier depuis la corbeille">
1. Double-cliquez sur la **Corbeille** : sur le bureau (Windows) ou à droite du Dock (Mac).
2. Faites un clic droit sur le fichier.
3. Choisissez **Restaurer** (Windows) ou **Remettre** (Mac). Il retourne à sa place d'origine.
</Etapes>

<Attention>
**Vider la corbeille** efface définitivement les fichiers. Vérifiez son contenu avant. Les fichiers supprimés d'une clé USB, eux, ne passent souvent pas par la corbeille.
</Attention>
