## Quelles sont les touches spéciales du clavier ? \{#touches-speciales\}

<Definition terme="touche spéciale">
Une touche spéciale n'écrit pas de lettre. Elle donne un ordre à l'ordinateur ou change ce que font les autres touches.
</Definition>

**À quoi ça sert.** Effacer, passer à la ligne, écrire en majuscules, et surtout faire des <Terme id="raccourci-clavier">raccourcis clavier</Terme> : une combinaison de touches qui remplace plusieurs clics.

Sur un Mac, deux touches changent de nom :

- <Touches k="⌘" /> **Commande** (<Terme id="commande">cmd</Terme>) remplace <Touches k="Ctrl" /> pour presque tous les raccourcis ;
- <Touches k="⌥" /> **Option** (<Terme id="option">alt</Terme>) remplace <Touches k="Alt Gr" /> pour les symboles.

<Astuce>
Un raccourci s'écrit avec un « + » : <Touches k="Ctrl+C" />. Cela veut dire : **maintenez** <Touches k="Ctrl" /> enfoncée, appuyez sur <Touches k="C" />, puis relâchez les deux.
</Astuce>

## Comment taper @, € ou une majuscule accentuée ? \{#caracteres-speciaux\}

Certains caractères sont imprimés en petit, en bas à droite d'une touche. On les obtient en maintenant une touche spéciale.

<Etapes titre="Comment taper É avec un code Alt">
1. Vérifiez que le voyant **Verr. Num** de votre clavier est allumé. Sinon, appuyez sur la touche Verr. Num.
2. Maintenez la touche <Touches k="Alt" /> enfoncée.
3. Tapez **0201** sur le <Terme id="pave-numerique">pavé numérique</Terme>, à droite du clavier.
4. Relâchez <Touches k="Alt" /> : le É apparaît.
</Etapes>

<Attention>
Les codes Alt ne marchent qu'avec le pavé numérique. Les chiffres de la rangée du haut ne fonctionnent pas. Sans pavé numérique (ordinateur portable), copiez le caractère depuis un autre texte, puis collez-le.
</Attention>

## Comment copier, couper et coller un texte ? \{#copier-coller\}

<Definition terme="copier-coller">
Copier, c'est dupliquer un texte ou une image pour le placer ailleurs, sans le retaper. L'original ne bouge pas.
</Definition>

**À quoi ça sert.** Recopier un numéro de dossier, une adresse, un lien, un passage d'e-mail dans un formulaire ou un document.

Ce que vous copiez part dans le <Terme id="presse-papiers">presse-papiers</Terme> : une mémoire invisible de l'ordinateur. Il ne garde qu'un seul élément : une nouvelle copie remplace la précédente.

<Raccourcis
  legende="Les cinq raccourcis de base"
  lignes={[
    ['Tout sélectionner', '<kbd>Ctrl</kbd> + <kbd>A</kbd>', '<kbd>⌘</kbd> + <kbd>A</kbd>'],
    ['Copier', '<kbd>Ctrl</kbd> + <kbd>C</kbd>', '<kbd>⌘</kbd> + <kbd>C</kbd>'],
    ['Couper (déplacer)', '<kbd>Ctrl</kbd> + <kbd>X</kbd>', '<kbd>⌘</kbd> + <kbd>X</kbd>'],
    ['Coller', '<kbd>Ctrl</kbd> + <kbd>V</kbd>', '<kbd>⌘</kbd> + <kbd>V</kbd>'],
    ['Annuler la dernière action', '<kbd>Ctrl</kbd> + <kbd>Z</kbd>', '<kbd>⌘</kbd> + <kbd>Z</kbd>'],
  ]}
/>

<Etapes>
1. <Terme id="selectionner">Sélectionnez</Terme> le texte : cliquez au début, maintenez le bouton de la souris, glissez jusqu'à la fin, relâchez. Le texte apparaît surligné.
2. Copiez avec <Touches k="Ctrl+C" /> (Mac : <Touches k="⌘+C" />).
3. Cliquez à l'endroit où vous voulez placer le texte.
4. Collez avec <Touches k="Ctrl+V" /> (Mac : <Touches k="⌘+V" />).
</Etapes>

Essayez ici, sans risque :

<Astuce>
Une erreur ? <Touches k="Ctrl+Z" /> annule la dernière action. Vous pouvez l'utiliser plusieurs fois de suite.
</Astuce>

<Attention>
**Couper** retire le texte de son emplacement. Tant que vous ne l'avez pas collé, il n'existe que dans le presse-papiers : si vous copiez autre chose entre-temps, il est perdu. Préférez **copier**, puis effacez l'original une fois le collage réussi.
</Attention>

## Quels raccourcis connaître sur Windows ? \{#raccourcis-windows\}

Quelques raccourcis font gagner beaucoup de temps. La touche <Touches k="⊞" /> est la touche Windows, entre <Touches k="Ctrl" /> et <Touches k="Alt" />.

<Raccourcis
  legende="Raccourcis utiles sur Windows"
  lignes={[
    ['Passer d’une fenêtre ouverte à une autre', '<kbd>Alt</kbd> + <kbd>Tab</kbd>'],
    ['Voir le bureau (tout réduire)', '<kbd>⊞</kbd> + <kbd>D</kbd>'],
    ['Ouvrir l’Explorateur de fichiers', '<kbd>⊞</kbd> + <kbd>E</kbd>'],
    ['Verrouiller l’ordinateur quand je m’absente', '<kbd>⊞</kbd> + <kbd>L</kbd>'],
    ['Faire une capture d’une partie de l’écran', '<kbd>⊞</kbd> + <kbd>Maj</kbd> + <kbd>S</kbd>'],
    ['Retrouver mes dernières copies', '<kbd>⊞</kbd> + <kbd>V</kbd>'],
    ['Fermer le logiciel ouvert', '<kbd>Alt</kbd> + <kbd>F4</kbd>'],
  ]}
/>

<Etapes titre="Comment faire une capture d'écran sur Windows">
1. Appuyez sur <Touches k="⊞+Maj+S" />. L'écran s'assombrit.
2. Avec la souris, tracez un rectangle autour de la zone à garder.
3. Relâchez : l'image est copiée dans le presse-papiers.
4. Collez-la avec <Touches k="Ctrl+V" /> dans un e-mail ou un document.
</Etapes>

<Astuce>
<Touches k="⊞+V" /> ouvre l'historique du presse-papiers, qui garde vos dernières copies. Il n'est pas activé au départ : la première fois, Windows propose de l'activer. Il s'efface à chaque redémarrage.
</Astuce>

## Quels raccourcis utiliser dans le navigateur ? \{#raccourcis-navigateur\}

Le <Terme id="navigateur">navigateur</Terme> est le logiciel qui affiche les sites web. Ces raccourcis marchent dans Chrome, Edge et Firefox. Sur Mac, remplacez <Touches k="Ctrl" /> par <Touches k="⌘" />.

## Quels sont les équivalents sur Mac ? \{#raccourcis-mac\}

Sur Mac, la plupart des raccourcis utilisent la touche <Touches k="⌘" /> **Commande**, de chaque côté de la barre d'espace.
