## Comment réserver un billet ? \{#reserver\}

<Etapes>
1. Ouvrez l'appli ou le site **SNCF Connect** (site officiel : sncf-connect.com).
2. Indiquez la **gare de départ**, la **gare d'arrivée**, la **date** et le nombre de voyageurs.
3. Ajoutez votre **carte de réduction** si vous en avez une.
4. Comparez les trains (horaires, durée, prix) et lisez les **conditions** du tarif.
5. Choisissez votre place si proposé, puis payez.
</Etapes>

## Comment garder son billet sur le téléphone ? \{#billet\}

Le billet apparaît dans l'appli, onglet **Voyages**, avec un **QR code** que le contrôleur scanne. Il arrive aussi par e-mail en PDF.

<Astuce>
Faites une **capture d'écran** du QR code avant le départ : elle sert de secours si le réseau manque dans le train. Le billet électronique peut aussi être réimprimé.
</Astuce>

La carte coûte environ 49 € par an : elle devient rentable dès quelques allers-retours. Vérifiez le prix et les conditions sur SNCF Connect.

## Comment échanger ou se faire rembourser ? \{#echanger\}

<Etapes>
1. Dans l'appli, ouvrez **Voyages**, puis le billet concerné.
2. Touchez **Échanger** ou **Annuler** : l'appli indique les frais éventuels avant de confirmer.
3. Le remboursement revient sur le moyen de paiement utilisé.
</Etapes>

<Attention>
Les conditions dépendent du tarif : avec une carte Avantage, l'échange et le remboursement sont gratuits jusqu'à 7 jours avant le départ, puis avec une retenue. Certains billets (tarifs non flexibles, OUIGO) sont peu ou pas échangeables. Lisez les conditions avant d'acheter.
</Attention>
