## Qu'est-ce que le cloud ? \{#definition\}

<Definition terme="cloud">
Le <Terme id="cloud">cloud</Terme> (nuage) est un espace de stockage sur Internet. Vos fichiers sont gardés sur les serveurs d'une entreprise et accessibles depuis tous vos appareils.
</Definition>

**À quoi ça sert.** Sauvegarder ses photos et documents, les retrouver sur un nouvel appareil, les partager avec un proche.

## Qu'est-ce que la synchronisation ? \{#synchronisation\}

La synchronisation garde les mêmes fichiers partout : une photo prise sur le téléphone apparaît sur l'ordinateur, un document modifié sur l'ordinateur est à jour sur le téléphone.

<Attention>
La synchronisation marche dans les deux sens : **supprimer** un fichier dans un dossier synchronisé le supprime **partout**. Vérifiez avant un grand ménage. La corbeille du service garde en général les fichiers supprimés quelque temps.
</Attention>

## Comment partager un fichier par lien ? \{#partager\}

<Etapes>
1. Dans Google Drive, iCloud Drive ou OneDrive, faites un clic droit (ou appui long) sur le fichier.
2. Choisissez **Partager**, puis **Copier le lien**.
3. Réglez l'accès : **lecture seule** pour que la personne puisse voir sans modifier.
4. Collez le lien dans un e-mail ou un message.
</Etapes>

<Astuce>
C'est la solution pour envoyer un fichier trop lourd pour une pièce jointe (voir « Envoyer et ouvrir une pièce jointe »).
</Astuce>
