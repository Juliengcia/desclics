## Comment se connecter au Wi-Fi de sa box ? \{#wi-fi\}

<Etapes>
1. Repérez le **nom du réseau** et le **mot de passe** (ou clé WPA) sur l'étiquette sous ou derrière la box.
2. Sur le téléphone, ouvrez **Paramètres → Connexions → Wi-Fi** (Android) ou **Réglages → Wi-Fi** (iPhone). Sur l'ordinateur, cliquez sur l'icône Wi-Fi en bas à droite (Windows) ou en haut (Mac).
3. Touchez le nom de votre réseau.
4. Tapez le mot de passe en respectant majuscules et chiffres, puis **Se connecter**.
5. L'appareil s'en souviendra : la connexion sera automatique ensuite.
</Etapes>

## Comment utiliser les données mobiles ? \{#donnees-mobiles\}

Hors de chez vous, le téléphone utilise le réseau <Terme id="4g-5g">4G ou 5G</Terme> de votre forfait. Le volume est limité par le forfait (en Go).

- **Activer ou couper** : réglages rapides → icône des **données mobiles**.
- **Surveiller sa consommation** : Paramètres → Connexions → Utilisation des données (Android) ; Réglages → Données cellulaires (iPhone).
- **Couverture** : la carte officielle de l'Arcep, **monreseaumobile.arcep.fr**, montre la couverture de chaque opérateur.

## Comment partager sa connexion ? \{#partage\}

Le téléphone peut servir de box pour un ordinateur ou une tablette :

- **Android** : Paramètres → Connexions → **Point d'accès mobile et modem** → activez **Point d'accès mobile**.
- **iPhone** : Réglages → **Partage de connexion** → activez **Autoriser d'autres utilisateurs**.

Connectez ensuite l'ordinateur à ce réseau Wi-Fi comme à une box. Le partage consomme les données de votre forfait.

## Le Wi-Fi public est-il sûr ? \{#wi-fi-public\}

<Attention>
Sur un Wi-Fi public (gare, café, hôtel), évitez la banque, les achats et les démarches sensibles. Préférez vos données mobiles pour ces usages.
</Attention>

## Comment connecter un appareil en Bluetooth ? \{#bluetooth\}

<Definition terme="Bluetooth">
Le <Terme id="bluetooth">Bluetooth</Terme> relie sans fil deux appareils proches : écouteurs, enceinte, voiture, montre.
</Definition>

<Etapes>
1. Mettez l'appareil (écouteurs, enceinte) en **mode appairage** : souvent un bouton maintenu jusqu'à ce qu'un voyant clignote.
2. Sur le téléphone, ouvrez **Bluetooth** dans les paramètres et activez-le.
3. Touchez le nom de l'appareil quand il apparaît.
4. La prochaine fois, la connexion se fera automatiquement.
</Etapes>
