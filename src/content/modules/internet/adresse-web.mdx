## Comment lire une adresse web ? \{#url\}

<Definition terme="adresse web (URL)">
L'<Terme id="url">adresse web</Terme> (ou URL) indique où se trouve une page. Elle s'affiche dans la barre en haut du navigateur.
</Definition>

Exemple : **https://www.service-public.gouv.fr/particuliers/vosdroits/F1234**

<ARetenir>
Lisez le nom de domaine **en partant du .fr ou du .com, vers la gauche**. Dans « impots.gouv.fr.paiement-rapide.com », le vrai site est « paiement-rapide.com ».
</ARetenir>

## Que signifie le cadenas ? \{#cadenas\}

Le cadenas (et le **https**) signifie que les échanges entre vous et le site sont **chiffrés** : personne ne peut les lire en route. Il ne dit rien de l'honnêteté du site : les faux sites ont aussi un cadenas.

## Comment reconnaître un site officiel ? \{#officiel\}

- Les sites de l'État finissent par **.gouv.fr**.
- Les grands organismes ont leur propre domaine : ameli.fr, caf.fr, francetravail.fr, laposte.fr.
- En cas de doute, passez par **service-public.gouv.fr**, qui renvoie vers le bon site.
