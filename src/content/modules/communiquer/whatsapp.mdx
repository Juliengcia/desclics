## Comment installer WhatsApp ? \{#installer\}

<Etapes>
1. Installez **WhatsApp Messenger** (éditeur WhatsApp LLC) depuis le Play Store ou l'App Store.
2. Ouvrez-le, acceptez les conditions, tapez votre numéro de mobile.
3. Saisissez le code à 6 chiffres reçu par SMS.
4. Indiquez votre prénom et, si vous le souhaitez, une photo.
5. Autorisez l'accès aux contacts : vos proches qui utilisent WhatsApp apparaissent.
</Etapes>

<Attention>
Le code à 6 chiffres reçu par SMS ne se donne à personne. Un message « Je t'ai envoyé un code par erreur, peux-tu me le renvoyer ? » sert à voler votre compte WhatsApp.
</Attention>

## Comment écrire et envoyer un message vocal ? \{#ecrire\}

<Etapes titre="Envoyer un message écrit">
1. Touchez l'icône **Nouvelle discussion** (bulle avec un +), puis un contact.
2. Touchez le champ **Message** en bas, écrivez.
3. Touchez la **flèche** verte pour envoyer.
</Etapes>

<Etapes titre="Envoyer un message vocal">
1. Dans la discussion, **maintenez** le **micro** à droite du champ de texte.
2. Parlez sans relâcher.
3. Relâchez : le message part. Pour annuler, faites glisser le doigt vers la gauche avant de relâcher.
</Etapes>

<Astuce>
Faites glisser le micro vers le haut (cadenas) pour enregistrer sans garder le doigt appuyé. Touchez ensuite la flèche pour envoyer.
</Astuce>

## Comment envoyer une photo, un GIF ou un lien ? \{#photos-gif-liens\}

- **Photo ou vidéo** : touchez le **trombone** (ou **+**), puis **Galerie** ; ou l'**appareil photo** pour en prendre une.
- **GIF** (petite image animée) : touchez l'icône **émoticône** du clavier, puis **GIF**, cherchez un mot (« merci »).
- **Lien** : copiez l'adresse d'une page, puis collez-la dans le message (appui long dans le champ → Coller). Un aperçu s'affiche.

## Comment appeler et raccrocher ? \{#appeler\}

<Etapes>
1. Ouvrez la discussion avec la personne.
2. En haut, touchez le **combiné** (appel vocal) ou la **caméra** (appel vidéo).
3. Pour **raccrocher**, touchez le **bouton rouge** en bas de l'écran d'appel.
4. Si vous êtes sorti de l'écran d'appel, touchez la **barre verte** en haut pour y revenir.
</Etapes>

<Astuce>
Pendant un appel vocal, touchez la caméra pour passer en vidéo. L'autre personne doit accepter.
</Astuce>

## Comment fonctionnent les groupes ? \{#groupes\}

- **Créer** : Nouvelle discussion → **Nouveau groupe**, choisissez les membres, donnez un nom.
- **Couper les notifications** : touchez le nom du groupe → **Notifications** → **Mettre en sourdine**.
- **Quitter** : nom du groupe → tout en bas, **Quitter le groupe**.

## Comment protéger sa vie privée ? \{#confidentialite\}

<Etapes>
1. Ouvrez **Paramètres** (Android : trois points → Paramètres ; iPhone : onglet Vous ou Réglages), puis **Confidentialité**.
2. **Groupes** : choisissez **Mes contacts**, pour que des inconnus ne puissent pas vous ajouter à un groupe.
3. **Photo de profil** et **Vu à** : limitez à **Mes contacts**.
4. **Sauvegarde** : Paramètres → **Discussions** → **Sauvegarde des discussions** : activez une sauvegarde régulière.
</Etapes>
