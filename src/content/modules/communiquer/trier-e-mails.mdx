## Qu'est-ce que le dossier spam ? \{#spam\}

<Definition terme="spam">
Un <Terme id="spam">spam</Terme> est un message non désiré : publicité, arnaque, chaîne. La messagerie les range automatiquement dans le dossier **Spam** ou **Courrier indésirable**.
</Definition>

<Astuce>
Un e-mail attendu (code de connexion, confirmation de rendez-vous) n'est pas arrivé ? Regardez d'abord dans le dossier Spam. S'il y est, marquez-le **Non spam**.
</Astuce>

## Comment signaler un spam ? \{#signaler\}

1. Ouvrez ou sélectionnez le message.
2. Touchez **Signaler comme spam** (ou **Indésirable**). Pour une tentative d'arnaque, choisissez **Signaler un hameçonnage** si proposé.
3. Le message part dans le dossier Spam, et les suivants du même expéditeur aussi.

Vous pouvez aussi signaler les spams sur **signal-spam.fr**.

## Comment se désabonner des lettres d'information ? \{#desabonner\}

<Etapes>
1. Ouvrez la lettre d'information d'un site que vous connaissez (magasin, journal).
2. Tout en bas du message, cliquez sur **Se désabonner** (souvent en petit).
3. Confirmez sur la page qui s'ouvre. Gmail propose parfois un bouton **Se désabonner** à côté de l'expéditeur.
</Etapes>

<Attention>
Ne cliquez pas sur « Se désabonner » dans un spam d'un expéditeur inconnu : vous confirmeriez que votre adresse est active. Signalez-le comme spam.
</Attention>

## Comment ranger ses e-mails ? \{#ranger\}

- **Outlook, Mail, messageries d'opérateur** : créez des **dossiers** (Impôts, Santé, Famille) et faites glisser les messages dedans.
- **Gmail** : utilisez des **libellés** (étiquettes). Un message peut en avoir plusieurs. Ouvrez le message, touchez les trois points, puis **Libellé**.
- **Archiver** retire le message de la boîte de réception sans le supprimer : il reste trouvable par la recherche.

## Que faire si la boîte est pleine ? \{#pleine\}

1. Dans la barre de recherche, tapez **larger:10M** (Gmail) ou triez par **taille** (Outlook) pour trouver les gros messages.
2. Supprimez ceux dont vous n'avez plus besoin, après avoir enregistré les pièces jointes utiles.
3. Videz le dossier **Corbeille** et le dossier **Spam**.
