## 1. Le mot de passe est-il vraiment oublié ? \{#verifier\}

Vérifiez que **Verr. Maj** n'est pas activé, que vous tapez la bonne **adresse e-mail**, et touchez l'**œil** à côté du champ pour voir ce que vous tapez.

## 2. Pour un site ou une messagerie \{#site\}

<Etapes>
1. Sur la page de connexion, touchez **Mot de passe oublié**.
2. Saisissez l'adresse e-mail ou le numéro du compte.
3. Ouvrez le message reçu (regardez dans **Spam**) et suivez le lien, ou tapez le code.
4. Choisissez un nouveau mot de passe, et enregistrez-le dans un gestionnaire.
</Etapes>

## 3. Pour le compte Google ou Apple \{#google-apple\}

Depuis un autre appareil, tapez vous-même **g.co/recover** (Google) ou **iforgot.apple.com** (Apple), puis suivez les étapes : code par SMS, validation sur un appareil déjà connecté, ou questions de récupération.

## 4. Pour le code du téléphone \{#code-telephone\}

<Attention>
Après trop d'essais, le téléphone se bloque. Sur iPhone et Android récents, retrouver l'accès passe souvent par une **réinitialisation**, qui efface le téléphone : vos données ne seront récupérables que si elles sont **sauvegardées** dans votre compte Google ou Apple. Faites-vous aider en boutique ou par le service après-vente avec une preuve d'achat.
</Attention>

## 5. Pour le code de la carte bancaire \{#code-carte\}

Demandez-le à votre banque : beaucoup d'applis bancaires permettent de **revoir son code** après validation. Sinon, l'agence peut vous le renvoyer par courrier. Après trois essais faux, la carte se bloque au distributeur.

<ARetenir>
Pour ne plus oublier : un **gestionnaire de mots de passe** retient tout, et un papier rangé à la maison garde les codes essentiels (téléphone, mot de passe maître).
</ARetenir>
